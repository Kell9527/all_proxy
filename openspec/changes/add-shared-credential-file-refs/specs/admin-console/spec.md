# Spec Delta

## Purpose

定义管理端对「共享凭据文件」的展示与操作：账号卡片上的凭据来源标注、路径脱敏，以及绑定 / 解绑共享凭据文件的入口。

## ADDED Requirements

### Requirement: 凭据来源展示

系统 SHALL 在账号卡片上标明凭据来源（内置存储或共享文件）。当凭据为文件引用时，界面 SHALL 展示**脱敏后**的路径而非完整绝对路径。

#### Scenario: 内置凭据

- **WHEN** 账号使用内置凭据引用
- **THEN** 卡片 SHALL 展示该引用本身

#### Scenario: 文件引用脱敏

- **WHEN** 账号的凭据为文件引用
- **THEN** 卡片 SHALL 展示经脱敏的路径（仅保留尾部路径段），MUST NOT 直接展示含用户名的完整绝对路径

#### Scenario: 完整路径可查

- **WHEN** 用户需要确认凭据文件的完整位置
- **THEN** 界面 SHALL 在提示信息中提供完整引用

### Requirement: 绑定与解绑共享凭据文件

系统 SHALL 提供在账号卡片上绑定 / 解绑共享凭据文件的操作。

#### Scenario: 绑定共享文件

- **WHEN** 用户为一个账号指定共享凭据文件的绝对路径
- **THEN** 系统 SHALL 完成绑定，并在该文件当下不可读时明确提示该账号会被视为凭据缺失

#### Scenario: 解绑共享文件

- **WHEN** 用户对一个文件引用账号执行解绑
- **THEN** 系统 SHALL 提示该操作会使凭据不再与外部文件同步，并在确认后完成转存

#### Scenario: 路径非法

- **WHEN** 用户给出相对路径或空路径
- **THEN** 界面 SHALL 展示可读的错误说明，且不改动账号
